# Surface brief: qtiming documentation site

Scope: the public documentation site (MkDocs, custom theme), GitHub Pages. Visitor mode: Read.
Audience and job: circuit authors reading to understand a verdict and what to do next. Proof: real command transcripts. Constraints: Plans/ stays off the site; nothing invented (no testimonials, figures, adoption claims).

## Direction contract

THESIS: Documentation set as the part datasheet a hardware engineer already trusts: every claim is a numbered row with its condition and its source. Refuses the sidebar-article template with a hero and feature cards.
OWN-WORLD: White page, near-black ink, one datasheet blue, hairline D9DEE4 rules. B612 for labels, headings and tables; Source Serif 4 for prose; B612 Mono only for code and values. Tables with ruled headers, numbered notes in the margin, waveform figures drawn in inline SVG. Recognisable with the words removed: the ruled document-number header strip and the footnote margin.
STORY: A reader learns what a verdict claims and assumes, runs check on their own program, and trusts it because limits are stated as plainly as results.
